# Manuscript results ledger

`manuscript_results.tsv` is regenerated by
`analysis/build_manuscript_results.py`. It records quantitative results used in
the Results, main-figure legends, and supplementary analyses that materially
support those claims.

Every row is recalculated from a compact release source table or frozen JSON
summary identified in `source_table`; manuscript prose is never used as a
numeric source. The ledger includes effect estimates, ranks, correlations,
confidence intervals or heterogeneity summaries where available, held-out
model comparisons, and key sample counts. It does not duplicate fixed design
parameters (input length, track choice, seeds, thresholds), which are recorded
in `outputs/run_manifests/panel_analysis_parameters.tsv` and the prespecified
run manifests.

The ledger is intentionally long-form: a result can be traced to one source,
one analysis identifier, one model regime, and one stated population or sample
size. Values should be quoted from this file rather than transcribed from
figures.
