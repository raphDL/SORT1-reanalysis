   from **Currin et al., Genome Research (2025), Zenodo 15025748 / GEO
   GSE264684**, not the separate Currin et al. AJHG 2021 study. `SOURCES.tsv`
   and the manifest now record the data actually used.
2. Figure 4B's previously missing compact table was recovered by exact hash
   and added to the release.

   from older manuscript drafts. The release ledger is authoritative and the
   prose must be checked against it before submission.
4. Figure 1B and 1C canonical assets are PDFs, not SVGs. Their manifest paths
   now use the correct file type; validation checks file signatures to prevent
   extension/content mismatches.
